# Wasserschadenmodell
Dieses Repo enthält Daten für das MA-Projekt "Wasserschadenmodell". Alle Inhalte wurden im Rahmen des Formelbuchprojekts an der Arbeitsstelle [Regesta Imperii - Regesten Kaiser Friedrichs III.](https://ri.bbaw.de/de) der Berlin-Brandenburgischen Akademie der Wissenschaften erstellt.

Eine Projektzusammenfassung findet sich hier: Heinicker/Skidzun, [Das "Formelbuchprojekt". Digitale und analoge Ansätze zur Erschließung einer Handschrift aus dem 15. Jahrhundert](https://doi.org/10.5281/zenodo.23615263), in: RI colloquium digitale - Living Book of Abstracts, 2026.

## Inhalt
Das Repo enthält Daten zu zwei Tests:

1) Test-leicht-mittelgradig
    - Bilder: verwendete Bilddateien (3 unbearbeitete Digitalisate sowie je zwei Verfremdungen derselben)
    - Transkriptionen: Ground Truth und Transkriptionen der Modelle
    - Auswertung-Test-leicht-mittel.md: Testergebnisse

2) Test-schwer
    - Bilder: verwendete Bilddateien (10 unbearbeitete Digitalisate)
    - Transkriptionen: Ground Truth und Transkriptionen der Modelle
    - Auswertung-Test-schwer.md: Testergebnisse
    - line_counts-comp.ods: Vergleich der Zeilenlängen

3) transcription-rules.md: Transkriptionsrichtlinien des Formelbuchprojekts


## Getestete Modelle
Die Testdaten entstammen einem Vergleich folgender Modelle:
- Wasserschadenmodell: [Regg.F.III-damaged - ATR model for damaged text](https://doi.org/10.5281/zenodo.23313428)
- Formelbuchmodell: [Regg.F.III formulary transcription model (allographetic)](https://doi.org/10.5281/zenodo.21276311)

## Verantwortlichkeit
